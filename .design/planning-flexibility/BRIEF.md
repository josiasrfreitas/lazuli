# Class planning flexibility

Operate mode. Extend the existing class planning tab with Lazuli's semantic tokens and dark
operational cards. Issues #275 and #278 supply the scope; the owner explicitly requested these
flows and approved date-based closure with written confirmation, and recurring collective
appointments with professor, weekday/time and final date. Existing student appointments remain
separate from collective class encounters; collective attendance/content uses the class session.

Remove the duplicated heading/date/track banner. Put one contextual “Ajustar aulas” action inside
the availability card; branch into adding recurring encounters or ending future lessons. Start
changes are available only while the original and replacement start dates are in the future.
Use the existing content card for “Último conteúdo trabalhado” and “Próximo”.

The explorer shows every unit and lesson together, with completed work in semantic success color,
pending projected dates and expandable activity details. Project pending work against actual
remaining session capacity, including collective appointments beyond the period; retain performed
history and plan revisions. Delight thesis: the operator sees a difficult schedule become feasible
in a clear before/after capacity preview and sees the curriculum adapt immediately after saving.
No confetti, invented progress, competing controls, generic tables or global visual replacement.

Scheduling skips school closures, checks teachers and current roster conflicts, explicitly confirms
outside-period dates, and records an attributed audit event. Ending preserves evidence and linked
guests; server validation requires current impact fingerprint, sufficient remaining capacity and
the exact written phrase. Regular cancellations are logical status updates.

Use Orca browser on lazuli.lazuli.localhost, desktop and narrow; real writes only to the synthetic
DEMO classes. No lint/typecheck/build/test-runner/detector passes per the user's instruction.

Owner refinement: recommend adding when the known deficit is negative, ending when content has
margin or is complete, and neither when tight/unknown. Add a live two-column scheduling composition:
left fields, right capacity before/after, updated from the real conflict-checked recurrence preview.
Default to the class's current teacher. Preserve the outside-period confirmation as the final step.
