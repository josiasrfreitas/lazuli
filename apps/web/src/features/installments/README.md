# Receivables presentation

Keep monetary cells on one line. Additional financial detail must not increase the height of a table row; use separate columns and hover/focus descriptions.

- **Valor nominal** shows the original installment amount.
- **Valor pago** shows actual receipts, including partial receipts; use “—” when nothing has been received. Waiver is not payment.
- Show an inline discount indicator only in **Valor pago**, when a discount has been applied. Its percentage must be available on hover and keyboard focus. Do not show available discount conditions or indicators in **Valor nominal**.
- Situation identifies partial payment and preserves overdue information. A partial receipt does not imply that an on-time discount was applied.
- Flat and payer-group tables use the same monetary presentation. The payer-group summary retains the collectible balance.
