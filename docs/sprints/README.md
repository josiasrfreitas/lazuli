# Sprint Plans

Local sprint plans and agent-ready issue trackers live here. Each sprint gets its own folder so the
planning record, dependency map, templates, and promoted issues stay together.

## Naming

Use this folder pattern:

```text
SP-###-YYYY-MM-DD-<slug>/
```

- `SP-###` is the stable sprint code, assigned sequentially.
- `YYYY-MM-DD` is the planning date.
- `<slug>` is a short readable scope name.
